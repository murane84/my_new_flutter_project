How to install on Android

  1. Tap Download for Android and open the file when it finishes.
  2. If Android asks, allow your browser to install unknown apps.
  3. Play Protect may not know Aluta yet — tap More details → Install anyway.
  4. “App not installed”? Use the universal APK (link under the button).
  5. Already have Aluta? Installing updates it — your chats stay.

After this, Aluta tells you itself when a new version is ready.
